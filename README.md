## 建议阅读顺序

1. 先明确你的主体类型（个人 / 组织）与目标平台。  
2. 按目录打开对应短文，勾选材料与注意事项。  
3. 回到 **官方帮助中心 / Console / Developer 后台** 完成实际操作。  
4. 若需要更细的中文图文步骤，可参考文末「延伸阅读」。
