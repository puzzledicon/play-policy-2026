如何应对目标 API 级别要求

下面按实际后台操作顺序整理。建议边看边打开对应控制台页面，逐项完成。

Google Play政策目标APIAPI 36照片权限视频权限开发者验证应用转移政策状态

适用场景

满足 Play 对目标 API 级别的更新要求。

操作步骤

  1. 查看 Console 截止日期与延期入口。
  2. 升级 AGP、compileSdk、targetSdk。
  3. 回归权限、后台、通知与显示变更。
  4. 修复依赖不兼容并跑核心路径。
  5. 先测试轨道，再逐步生产。

注意事项

  • 延期非长期方案。
  • 第三方 SDK 落后是常见阻塞。
  • 行为变更需完整回归登录/支付/推送。
